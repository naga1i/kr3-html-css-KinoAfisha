# Учебный frontend-проект «KinoAfisha»

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт кинотеатра «KinoAfisha» с использованием CSS-фреймворка Bootstrap 5, методологии БЭМ, семантической HTML-разметки и интерактивных сценариев на JavaScript.

## Структура проекта

- `index.html` — главная страница (заголовок с кнопкой «Купить билет», блок преимуществ кинотеатра, блок «Сейчас в кино», модальное окно быстрого бронирования);
- `afisha.html` — страница афиши (блок фильтров по жанру и возрастному рейтингу, сетка из 8 карточек фильмов с постерами, ценами и бейджами «Премьера», «Хит», «Скоро»);
- `contacts.html` — страница контактов (раздел «О нас» с историей кинотеатра, количеством залов и фотографией зала, контактная информация и схема проезда, блок часто задаваемых вопросов с раскрывающимся списком);
- `booking.html` — страница бронирования билетов (форма выбора фильма, даты, сеанса, количества билетов и типа места, интерактивная схема зала с выбором мест, таблица цен на билеты и расчёт итоговой стоимости заказа);
- `css/style.css` — пользовательский файл стилей (CSS-переменные, БЭМ-компоненты, стили схемы зала и карточек);
- `js/main.js` — скрипт главной страницы, модального окна быстрого бронирования, фильтрации афиши и расчёта бронирования мест в зале;
- `images/` — постеры фильмов и фотография кинозала в формате JPG;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Используемые технологии

- HTML5 (семантическая разметка, формы, таблицы, `dialog`, `details`/`summary`);
- CSS3 (CSS-переменные, Flexbox, CSS Grid, методология БЭМ);
- Bootstrap 5.3 (адаптивная сетка, контейнеры, навигация, карточки, бейджи, таблицы, формы, утилиты);
- JavaScript (ES6+): модальное окно, валидация форм, фильтрация карточек афиши, интерактивная схема кинозала и динамический подсчёт стоимости билетов;
- Git и GitHub.

## Реализованные страницы и функциональность

### 1. Главная страница (`index.html`)
- Первый экран (Hero-секция) с заголовком, описанием кинотеатра и кнопкой «Купить билет».
- Блок преимуществ кинотеатра: залы IMAX лазерного проецирования, удобные кресла-реклайнеры VIP-класса, кинобар с карамельным попкорном и авторскими напитками.
- Блок «Сейчас в кино»: карточки актуальных фильмов с постерами, возрастным рейтингом (`6+`, `12+`, `16+`, `18+`), жанром, ценой и кнопками быстрого бронирования или перехода к выбору мест.
- Модальное окно с формой быстрого бронирования билетов (выбор фильма, сеанса, имени, телефона, количества билетов, валидация полей, блокировка прокрутки фона и сообщение об успешном бронировании).

### 2. Афиша (`afisha.html`)
- Блок фильтров (sticky-панель на десктопе): фильтрация по жанру («Все жанры», «Фантастика», «Боевик», «Драма», «Анимация», «Триллер») и по возрастному рейтингу (`6+`, `12+`, `16+`, `18+`), а также сортировка и сброс фильтров.
- Сетка из 8 карточек фильмов с постерами, жанром, возрастным рейтингом, ценой билета и тематическими бейджами («Премьера», «Хит», «Скоро»).
- Динамическая фильтрация карточек на стороне клиента с подсчётом найденных фильмов.

### 3. Контакты (`contacts.html`)
- Раздел «О нас»: история создания кинотеатра «KinoAfisha», ключевые показатели (6 современных кинозалов, 850 посадочных мест, экран IMAX 24 метра, звук Dolby Atmos) и фотография главного зала.
- Контактная информация: точный адрес, телефон кассы и поддержки, e-mail, ежедневный режим работы и подробное описание того, как добраться на метро и автомобиле.
- Блок часто задаваемых вопросов (FAQ) с раскрывающимся списком на базе семантических тегов `<details>` и `<summary>`.

### 4. Бронирование (`booking.html`)
- Форма бронирования: выбор фильма (с автоматической подстановкой при переходе со страниц сайта), даты показа, времени сеанса, количества билетов, категории билета / типа места, а также контактных данных зрителя.
- Интерактивная схема зала с экраном, рядами и местами трёх состояний: свободные, занятые и выбранные (включая VIP-ряды).
- Таблица цен на билеты для всех категорий: обычный, VIP, детский и студенческий (утренние, дневные и вечерние сеансы).
- Блок итоговой стоимости заказа с динамическим пересчётом цены, отображением выбранных мест и кнопкой «Забронировать».
