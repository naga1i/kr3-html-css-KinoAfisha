# Учебный frontend-проект «MovieMirea»

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт кинотеатра «MovieMirea» с использованием CSS-фреймворка Bootstrap 5, методологии БЭМ, семантической HTML-разметки и интерактивных сценариев на JavaScript.

## Структура проекта

- `index.html` — главная страница (заголовок с кнопкой «Купить билет», блок преимуществ кинотеатра, блок «Сейчас в кино», модальное окно быстрого бронирования);
- `afisha.html` — страница афиши (блок фильтров по жанру и возрастному рейтингу, сетка из 8 карточек реальных фильмов с официальными постерами, ценами и бейджами «Премьера», «Хит», «Скоро»);
- `contacts.html` — страница контактов (раздел «О нас» с историей кинотеатра, количеством залов и фотографией зала, контактная информация и схема проезда);
- `booking.html` — страница бронирования билетов (форма выбора фильма, даты, сеанса, количества билетов и типа места, индивидуальная интерактивная схема кинозала под каждый выбранный фильм и расчёт итоговой стоимости заказа);
- `css/style.css` — пользовательский файл стилей (CSS-переменные, БЭМ-компоненты, стили схемы зала и карточек);
- `js/main.js` — скрипт главной страницы, модального окна быстрого бронирования, фильтрации афиши и расчёта бронирования мест в зале;
- `images/` — постеры фильмов и фотография кинозала в формате JPG;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Используемые технологии

- HTML5 (семантическая разметка, формы, таблицы, `dialog`, `details`/`summary`);
- CSS3 (CSS-переменные, Flexbox, CSS Grid, методология БЭМ);
- Bootstrap 5.3 (адаптивная сетка, контейнеры, навигация, карточки, бейджи, таблицы, формы, утилиты);
- JavaScript (ES6+): модальное окно, валидация форм, фильтрация карточек афиши, интерактивная схема кинозала и динамический подсчёт стоимости билетов;
- Git и GitHub.

## Реализованные страницы и функциональность

### 1. Главная страница (`index.html`)
- Первый экран (Hero-секция) с главной премьерой недели, ближайшими сеансами и кнопкой «Купить билет».
- Блок преимуществ кинотеатра с реальными фотографиями: залы IMAX, удобные кресла, кинобар.
- Блок «Сейчас в кино»: карточки актуальных фильмов с постерами, возрастным рейтингом (`6+`, `12+`, `16+`, `18+`), жанром, ценой и кнопками быстрого бронирования или перехода к выбору мест.
- Блок отзывов посетителей кинотеатра с оценками и впечатлениями зрителей.
- Модальное окно с формой быстрого бронирования билетов.

### 2. Афиша (`afisha.html`)
- Блок фильтров (sticky-панель на десктопе): фильтрация по жанру и возрастному рейтингу (`6+`, `12+`, `16+`, `18+`), а также по статусу в прокате.
- Живой поиск по названию фильма и сортировка карточек по цене (по возрастанию/убыванию) и по алфавиту.
- Сетка из 8 карточек фильмов с постерами, жанром, возрастным рейтингом, ценой билета и тематическими бейджами («Премьера», «Хит», «Скоро»).

### 3. Контакты (`contacts.html`)
- Раздел «О нас»: история создания кинотеатра «MovieMirea», ключевые показатели (6 современных кинозалов, 850 посадочных мест, экран IMAX 24 метра, звук Dolby Atmos) и фотография главного зала.
- Контактная информация: точный адрес, телефоны, e-mail, режим работы, схема проезда и интерактивная Яндекс Карта.
- Блок часто задаваемых вопросов (FAQ) с раскрывающимся списком на базе семантических тегов `<details>` и `<summary>`.

### 4. Бронирование (`booking.html`)
- Форма бронирования: выбор фильма (с автоматической подстановкой при переходе со страниц сайта), даты показа, времени сеанса и контактных данных зрителя.
- Мини-конструктор кинобара («Добавить попкорн и напитки к билету») с автоматическим пересчётом итоговой суммы заказа.
- Интерактивная схема зала: у каждого фильма свой кинозал (Зал №1 IMAX Laser, Зал №2 Dolby Atmos, Зал №3 Семейный, Зал №4 Комфорт, Зал №5 Драйв, Зал №6 VIP Lounge) со своей раскладкой рядов, мест и занятых кресел.
- Таблица сравнения цен на билеты и тарифов (Обычный, VIP, Детский, Студенческий).
- Блок итоговой стоимости заказа с динамическим пересчётом цены, отображением выбранного зала, мест, позиций кинобара и кнопкой «Забронировать».

## CSS-архитектура и БЭМ-структура

В проекте используются:
- CSS-переменные в `:root` (цветовая палитра, шкала отступов, радиусы скруглений, ширина контейнера);
- состояния `:hover`, `:focus-visible`, `:disabled`, `:user-invalid`, `[aria-invalid="true"]`;
- Flexbox и CSS Grid в сочетании с сеткой и компонентами фреймворка **Bootstrap 5.3**;
- БЭМ-блоки: `site-header`, `site-nav`, `breadcrumbs`, `hero`, `section`, `advantage-card`, `movies-grid`, `movie-card`, `booking-dialog`, `booking-form`, `afisha-layout`, `afisha-filters`, `filters-form`, `about-cinema`, `contact-card`, `faq`, `hall-card`, `hall-grid`, `seat`, `order-summary`, `price-table`, `site-footer`.
